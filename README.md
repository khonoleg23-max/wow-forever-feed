# WoW Forever — русские ленты

Каждые 30 минут GitHub Actions забирает ленту Wowhead по WoW Forever, переводит заголовки и делает краткий пересказ на русском, а потом публикует две RSS-ленты через GitHub Pages:

- `docs/guides.xml` — гайды, хотфиксы, новости;
- `docs/professions.xml` — только профессии.

MonitoRSS читает эти ленты и выкладывает посты в Discord.

**Перевод.** Если в Settings → Secrets and variables → Actions добавлен секрет `ANTHROPIC_API_KEY`, перевод и пересказ делает Claude. Без секрета работает бесплатный онлайн-переводчик: он переводит заголовок и первые пару предложений.

Запустить вручную: вкладка Actions → «Translate WoW Forever feed» → Run workflow.

**Архив со старта беты.** `backfill.py` один раз собрал все статьи Wowhead по WoW Forever с 17.09.2026, которых нет в обычной ленте, перевёл заголовки и сгруппировал их по дням в дайджесты (`docs/archive.json`). Дайджесты стоят в конце лент. Чтобы MonitoRSS их не отбросил, в настройках обеих лент (Misc Settings → Article Date Checks) возраст статей выставлен в 0.

**Полный перевод в Discord.** Если в Settings → Secrets and variables → Actions заданы секреты `DISCORD_WEBHOOK_GUIDES`, `DISCORD_WEBHOOK_PROFESSIONS` и `DISCORD_WEBHOOK_ADDONS` (адреса вебхуков каналов), каждая новая статья целиком переводится на русский и отправляется прямо в канал. Длинные статьи приходят частями (1/3, 2/3…). Такие статьи не попадают в RSS, поэтому MonitoRSS их не дублирует. Полный текст на сайт не выкладывается. Проверка: Actions → Run workflow → в поле «Проверка» выбрать канал (guides, professions или addons).

**Цены аукциона.** `prices.py` 4 раза в день снимает аукцион WoW Forever (EU) с TheWoWDB по категориям (раз в день — вместе с бронёй и оружием) и копит историю материалов из `WATCHLIST` в `prices/history.json`. Раз в день Кадгар присылает сводку цен в канал профессий, при скачке цены больше чем на 40% за сутки — отдельное предупреждение.

**Профессии.** В #⚒-профы-и-аук у каждой профессии своя ветка: раз в день туда приходят «что выгодно крафтить» (цена на аукционе − 5% комиссии − материалы) и цены материалов. Рецепты WoW Forever взяты с Wowhead в `prices/recipes.json`, ветки и список профессий для ежедневной рассылки — `prices/config.json` (`daily`). Отчёт по одной профессии можно запросить вручную: Actions → «WoW Forever auction prices» → Run workflow → поле profession.
